# asas-lookups

Generic bilingual reference-data engine: lookup types → values → translations, plus aliases.
Stable codes in records, labels as translations; open types support get-or-create; reads are
ETag-cached; per-org value overrides layer on top of platform seeds.

Skeleton package — the implementation arrives with the pilot extraction (Teamy epic TEAMY-466).
See the repo README for the host contract.
